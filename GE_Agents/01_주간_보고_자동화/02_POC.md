# 주간 보고 자동화 POC

기획 문서: [[GE_Agents/01_주간_보고_자동화/00_기획]]  
사전 검증: [[GE_Agents/01_주간_보고_자동화/01_검증]]

## 목적과 범위

주간 보고 자동화의 제한된 핵심 흐름을 실제 환경에서 시험한다. 현재 POC 범위는 Slack 데이터를 GE에서 읽고, 결과를 Slack 메시지로 전송하는 단계까지다. 이메일 발송은 이 POC에서 아직 완료되지 않았다.

## 실제 진행 결과 (2026-10-15)

### 완료

- Slack을 GE에 데이터 스토어 형태로 연동했다.
- 인증 후 주간 데이터를 읽었다.
- 읽은 내용을 Slack 메시지로 전송했다.

위 결과는 사용자가 실제 환경에서 확인해 공유한 내용이다. 현재까지 주간 데이터 수집부터 Slack 전달까지의 기본 경로가 동작한다.

### 미완료: 이메일 발송

- 현재 사용하는 MailPlug는 GE의 데이터 스토어 또는 MCP 공식 지원 경로로 연결되지 않아 별도 연동 방법을 찾아야 한다.
- Gmail 메일 서비스도 현재 환경에서 사용하지 못했다.
- gmail.com이 아닌 도메인 때문인지는 확인되지 않았다. Google Workspace 계정, Gmail 사용 권한, GE 연결 설정 등 원인을 추가 확인해야 한다.

## 다음 POC 작업

- [ ] Slack 주간 데이터가 원본 기준으로 충분히 수집되는지 표본 비교
- [ ] Slack 메시지의 요약 내용과 원문 링크 확인
- [ ] MailPlug API/SMTP 또는 지원되는 별도 중계 경로 조사
- [ ] 대체 메일 발송 경로로 테스트 메일 전송
- [ ] 발송 권한, 승인 요구, 실패 및 중복 발송 처리 확인
- [ ] 메일 발송까지 포함한 전체 흐름을 제한된 주간 데이터로 재실행

## 완료 기준

- 지정한 한 주의 데이터가 의도한 채널에서 수집된다.
- 생성된 보고 항목이 Slack 원문으로 추적된다.
- 결정한 메일 경로로 테스트 수신자에게 메시지가 도착한다.
- 재실행과 부분 실패 시 동작을 확인하고 중복 발송 여부를 기록한다.

> 이 문서는 현재 POC 결과와 다음 실험을 기록한다. 실제 정기 운영 및 전체 수집 정확성이 확인되기 전까지 배포 완료로 간주하지 않는다.

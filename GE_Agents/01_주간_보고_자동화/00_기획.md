# 주간 보고 자동화

상위 문서: [[GE_Agents/00_GE_Agent_프로젝트_목록]]

## 목표

지난주 월요일부터 일요일까지 지정 Slack 채널의 업무 메시지를 요약하여 사용자에게 Slack 메시지로 전달한다. 각 요약에 Slack 원문 링크를 넣어 상세 내용으로 바로 이동할 수 있게 한다. Gmail 발송은 Google Workspace(GWS) 구독이 필요하므로 범위에서 제외한다.

> 원문의 “동완 왔던 메시지”는 “동안 올라온 메시지”로 해석했다. 특정 작성자를 의미했다면 작성자 필터를 추가한다.

## 필수 기능

- 대상 채널과 선택적 작성자 필터 설정.
- 한국시간 기준 지난주 메시지와 해당 기간의 스레드 답글 수집.
- 프로젝트별 진행 사항, 결정 사항, 이슈, 다음 할 일 분류.
- 항목별 원문 메시지 또는 스레드 링크 제공.
- 지정 사용자에게 주간 보고 Slack 메시지 전송.
- 예약 실행 후 Slack 전송 전에 사용자 승인을 받는다. 승인 없는 무인 발송은 현재 확인된 흐름에서 지원되지 않는다.
- 실행 이력과 수집 실패 범위 표시, 동일 주차 중복 전송 방지.

## 기간과 스레드 처리

- 시간대: Asia/Seoul.
- 기간: 지난주 월요일 00:00 이상, 이번 주 월요일 00:00 미만.
- 권장 실행 예시: 매주 월요일 09:00. 예약 실행은 가능하지만 Slack 메시지 전송은 별도 사용자 승인이 필요하다.
- 이전 주에 생성된 스레드라도 대상 주에 달린 답글은 포함한다.
- 맥락이 필요한 이전 메시지는 보조 자료로 읽되 보고 대상 기간의 성과와 구분한다.
- 메시지 수정·삭제와 접근 불가 채널의 처리 방침을 정한다.

## 추천 구조

1. 일정 트리거가 보고 기간을 계산한다.
2. Slack 데이터 스토어에서 관련 메시지를 찾는다.
3. 프로젝트명·채널·작성자·시간·원문 링크를 붙인다.
4. Gemini가 채널별 또는 프로젝트별로 요약한 뒤 통합한다.
5. 근거 링크와 수집 성공 여부를 확인한다.
6. Slack 메시지 초안을 준비하고 사용자가 승인하면 전송한 뒤 주차별 실행 기록을 남긴다.

초기 검증은 GE 기본 Slack 커넥터로 진행했고, 데이터 읽기와 Slack 메시지 전송 흐름은 POC에서 확인했다. 다만 데이터 스토어의 GCP 프로젝트/Billing 의존성과 실제 추가 비용은 미확인이다. 확인 전에는 정기 운영이나 범위 확대를 확정하지 않는다. 세부 내용은 [[GE_Agents/01_주간_보고_자동화/02_POC]]를 참고한다.

## 보고서 형식

```markdown
# 주간 업무 보고 | YYYY-MM-DD ~ YYYY-MM-DD

## 핵심 요약
- 이번 주 주요 변경 사항

## 프로젝트 A
- 진행: 내용 — [Slack 원문](실제_메시지_URL)
- 결정: 내용 — [Slack 원문](실제_메시지_URL)
- 이슈: 내용 — [Slack 원문](실제_메시지_URL)

## 다음 할 일
| 할 일 | 담당자 | 기한 | 근거 |
| --- | --- | --- | --- |
| 내용 | 명시된 담당자 또는 미정 | 명시된 날짜 또는 미정 | 원문 링크 |

## 수집 상태
- 대상 채널, 대상 기간, 성공·실패 범위
```

## 에이전트 지침 초안

> 지정된 기간과 채널의 메시지만을 근거로 주간 업무 보고를 작성한다. 진행·결정·이슈·다음 할 일을 프로젝트별로 구분하고 각 항목에 실제 Slack 원문 링크를 첨부한다. 담당자·기한·완료 여부가 명시되지 않으면 추측하지 않는다. 중복 논의는 통합하고 변경된 결정은 최신 근거를 우선한다. 수집 실패나 자료 부족을 보고서에 표시한다. 메시지를 Slack으로 전송하는 단계에서는 사용자 승인이 필요하며, 승인이 완료되지 않으면 전송 완료로 기록하지 않는다.

## 구축 체크리스트

- [ ] 채널·작성자 범위 및 공개·비공개 채널 접근 권한 결정
- [ ] 보고 대상 Slack 사용자와 승인 담당자 결정
- [ ] 메시지와 답글 수집 및 원문 링크 확인
- [ ] 샘플 한 주를 수동 보고와 비교하여 누락·왜곡 점검
- [ ] 예약 실행 후 사용자 승인 및 Slack 전송 경로 검증
- [ ] 중복 실행·부분 실패·승인 미처리 상태 처리
- [ ] Slack Connector의 GCP 비용과 조직 정책 적합성 확인

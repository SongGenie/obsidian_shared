# 원노트 Gemini 검색

상위 문서: [[GE_Agents/00_GE_Agent_프로젝트_목록]]

## 목표

오랫동안 원노트 섹션에 작성한 단위 작업 기록과 정리 내용을 Gemini Enterprise에서 자연어로 검색한다. 답변에는 해당 페이지 제목, 섹션, 수정일, 원문 링크를 제공한다.

## 필수 기능

- 선택한 노트북·섹션·페이지의 내용 수집.
- 제목·본문·노트북명·섹션명·수정일·원문 URL 보존.
- 자연어 질문과 정확한 기술명·프로젝트명 검색.
- 검색 근거를 이용한 답변과 원노트 원문 열기.
- 수정·삭제 내용의 색인 반영과 마지막 동기화 시각 표시.
- 여러 사용자가 이용할 경우 원본 접근 권한 반영.

## 추천 구조

1. Microsoft 계정의 사용자 위임 인증.
2. Microsoft Graph로 노트북·섹션·페이지 목록 조회.
3. 페이지 HTML 본문과 필요한 이미지·첨부 리소스 확보.
4. HTML 정리 후 제목·목록·표의 구조를 보존하여 텍스트화.
5. 긴 페이지는 소제목·날짜·단위 작업별로 분할.
6. 관리형 검색 데이터 스토어 등에 저장·색인.
7. GE 검색 도구 또는 커스텀 API/MCP로 검색하고 근거 기반 답변 생성.

## 연결 방식 선택

| 방식 | 용도 | 확인할 사항 |
| --- | --- | --- |
| Graph 기반 주기적 수집·색인 | 장기 기록 전체 검색 | 위임 인증, 증분 갱신, 삭제 반영 |
| Graph 실시간 호출 | 선택 페이지의 최신 내용 확인 | 응답 시간, 권한, API 필터 기능 |
| 내보낸 파일 변환·업로드 | 소규모 초기 검증 | 형식 지원, 파일별 제한, 원문 링크·갱신 유지 |

초기 권장은 Graph로 한 섹션을 수집하여 검색 품질을 검증하는 것이다. GE 커넥터 목록에서 OneNote 전용 항목은 확인되지 않았으며, OneDrive·SharePoint 연결이 원노트 본문 검색을 보장한다고 가정하지 않는다.

섹션을 파일 하나로 내보내더라도 용량 무관 연동이 되는 것은 아니다. .one 파일 등은 직접 색인 지원을 먼저 확인하고, 필요하면 페이지 단위 HTML·텍스트·PDF 변환을 검토한다. 파일 업로드 제한·문서 파싱·검색 정확도를 각각 확인한다.

## 인증과 동기화

Microsoft Graph OneNote API는 현재 app-only 인증을 지원하지 않는다. 사용자 위임 인증과 적절한 Notes 읽기 권한을 사용한다. 정기 수집에서는 토큰 갱신·재인증·동의 철회에 따른 실패 처리가 필요하다.

- 페이지 ID를 기준으로 중복 저장 방지.
- 수정 시각과 내용 해시로 변경 여부 비교.
- 페이지 목록을 주기적으로 대조하여 삭제·권한 회수 반영.
- OneNote에서 원하는 변경 추적 기능을 지원한다고 가정하지 않고 실제 API 범위 검증.
- 로컬 전용 노트라면 클라우드 동기화 또는 내보내기 경로부터 확인.

## 데이터와 검색 설계

필수 메타데이터: page_id, notebook_name, section_name, title, source_url, last_modified_at, synced_at, access_scope.

본문은 문맥을 유지하는 크기로 분할하고 각 조각에 페이지 ID·제목·소제목·원문 URL을 연결한다. 이미지·손글씨·스크린샷 안의 정보가 중요하면 별도 OCR 또는 멀티모달 추출을 추가한다. 첨부파일은 형식별 추출 지원 범위를 따로 정한다.

검색은 키워드와 의미 검색을 함께 평가한다. 별도 Vector DB 운영은 필수가 아니며 관리형 검색으로 먼저 검증한다. 최신 결정을 묻는 질문에서는 작성·수정 시각과 문서 내용을 함께 확인하여 과거 메모와 구분한다.

## 검색 예시

- “Ray-Ban 서버 연동 구조를 정리한 페이지 찾아줘.”
- “지난번 Unity 영상 재생 문제 해결 방법이 뭐였지?”
- “원노트에 적어둔 AX 구현 사례 중 번역 관련 내용만 보여줘.”

## 답변 형식

```markdown
찾은 내용의 요약과 근거 설명

- 출처: 페이지 제목 / 노트북 / 섹션
- 수정일: YYYY-MM-DD
- 동기화 시각: YYYY-MM-DD HH:mm
- [원노트 원문 열기](실제_페이지_URL)
```

## 에이전트 지침 초안

> 원노트에서 검색된 내용만을 근거로 답변한다. 페이지 제목·섹션·원문 링크와 관련 날짜를 제공한다. 문서에 적힌 사실과 추론을 구분한다. 관련 내용을 찾지 못하면 찾지 못했다고 답한다. 최신성에 영향을 줄 수 있는 동기화 지연이나 추출 실패가 있으면 표시한다. 사용자가 접근할 수 없는 문서는 검색·답변에 포함하지 않는다.

## 구축 체크리스트

- [ ] 개인 Microsoft 계정인지 회사 Microsoft 365 계정인지 확인
- [ ] 원노트 클라우드 저장 위치와 대상 섹션 확정
- [ ] Graph 앱 등록·위임 인증·읽기 권한 설정
- [ ] 텍스트·표·이미지·첨부파일이 있는 샘플 페이지로 추출 확인
- [ ] 실제 질문으로 정확한 페이지 검색과 원문 링크 검증
- [ ] 수정·삭제·권한 회수·재인증 시나리오 확인

# 연구개발 기획 Agent 검증 계획

기획: [[GE_Agents/06_연구개발_기획_Agent/00_기획]]  
초기 범위: [[GE_Agents/06_연구개발_기획_Agent/01_공고_모니터링]]

## 현재 상태

아래는 실행할 검증 계획이다. 실제 수집·GE 설정·API 연결·과금·정기 운영을 확인한 결과가 아니다. 제공 대화 속 기능 설명도 검증 완료 근거로 사용하지 않는다.

## POC 순서

1. NTIS·IRIS·기업마당과 전문기관 1곳의 실제 게시판·원문·이용 조건·API/RSS 제공 여부를 확인한다.
2. 기존 승인 환경과 앱 구독 범위 내 수집·저장·GE 입력 경로를 확인한다. 경로가 없으면 수동 확보 파일로 분석 POC를 진행하고 자동 수집은 미검증으로 남긴다.
3. 대표 공고 10건 안팎으로 아래 사례를 검증한다. 실제 변경 사례가 부족하면 명시적으로 표시한 시험 자료를 사용한다.
4. 공고 목록을 사람이 원문과 대조하고 오류를 수정한다.
5. 정기 실행·변경 이력·중복 방지가 검증된 후 하루 2회 운영을 검토한다. 외부 알림은 별도 검증한다.

## 검증 사례

| 사례 | 통과 조건 |
| --- | --- |
| 여러 포털의 동일 공고 | 대표 공고 하나와 모든 출처가 보존됨 |
| 제목이 같은 다른 차수·과제 | 별도 항목으로 유지됨 |
| 수정·마감 연장 | 변경 전후 값·근거·발견 시각이 남음 |
| 취소 공고 | 취소 상태가 표시되고 기존 기록이 보존됨 |
| 파일명 동일한 첨부 교체 | 내용 변경이 감지됨 |
| 본문과 세부 과제 일정 차이 | 실제 과제별 기간을 표시하거나 충돌로 보류함 |
| 스캔 PDF·HWP/HWPX 추출 실패 | 첨부 미확인과 누락 필드가 표시됨 |
| 정책 방향·수요조사 | 신청 가능한 확정 공고로 오인하지 않음 |
| 회사 정보 부재·조건 불충족 | 각각 확인 필요·불가로 구분됨 |
| 일부 사이트 접속 실패 | 신규 없음과 구분하며 정상 확인 범위가 표시됨 |
| 동일 데이터 재실행 | 공고·변경 이력·알림이 중복 생성되지 않음 |
| 출처 없는 마감·금액·자격 | 임의 생성 없이 미확인으로 남음 |

핵심 필드인 마감·자격·취소 상태에서 오판이 남으면 해당 기능의 운영 전환을 보류한다. 대표 표본 통과는 전국 공고의 완전 수집을 증명하지 않는다.

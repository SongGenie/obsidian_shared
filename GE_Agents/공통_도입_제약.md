# GE 도입 공통 제약

## 사용 가능한 구독 범위

현재 보유한 구독은 **Gemini Enterprise app**이다. GE Agent 프로젝트는 이 앱 구독에 이미 포함된 기능과 기존에 승인·보유한 서비스만을 우선 사용한다. Gemini Enterprise 앱 구독을 Google Workspace 또는 Google Cloud Platform 구독으로 간주하지 않는다.

## 사용 금지

적용 예외: 사용자는 2026-10-23 **[[GE_Agents/07_EmoAI_Agent/00_기획|EmoAI Agent]]에 한해 GCP 사용과 월 최대 USD 70의 예산**을 허용했다. 해당 프로젝트는 자체 예산·구축 조건을 우선 적용한다. 다른 프로젝트의 GCP 금지와 GWS 금지는 유지한다.

- Google Workspace(GWS) 서비스나 별도 라이선스를 사용하지 않는다. Gmail, Google Drive 등 GWS 서비스에 의존하는 설계와 대체 경로도 제외한다.
- Google Cloud Platform(GCP)의 프로젝트, API, 저장소, 실행 환경, 스케줄러 등 별도 GCP 리소스를 생성하거나 사용하지 않는다. Cloud Run 등 GCP에서 실행되는 커스텀 서버도 사용하지 않는다.
- 무료 체험, 무료 티어, 기존에 열려 있는 콘솔이라는 이유로 GWS/GCP 사용을 허용된 것으로 간주하지 않는다.
- GWS/GCP에 추가 비용을 발생시키는 구독, 라이선스, 사용량 과금, 리소스를 도입하지 않는다.

## 설계 판단 기준

1. 기능이 Gemini Enterprise 앱 구독에 포함되는지 확인한다.
2. 별도 GWS/GCP 계정, 프로젝트, 라이선스 또는 리소스가 필요한지 확인한다. 하나라도 필요하면 이 프로젝트의 설계 후보에서 제외한다.
3. 기존 MailPlug, Slack 등 이미 보유하고 승인된 서비스로 해결할 수 있는지 먼저 살핀다.
4. 기존 구독 범위를 넘거나 추가 비용이 필요한 선택지는 사용하지 않는다. 비용과 구독 범위가 확인되지 않은 연동은 도입하지 않는다.
5. Gemini Enterprise 앱 사용과 별도 GCP 리소스 사용을 혼동하지 않는다. 앱에서 제공되는 기능도 실제 구독 범위와 별도 과금 여부를 확인한 뒤 사용한다.


## Slack 데이터 스토어 관련 확인 사항

- Slack 데이터 스토어의 공식 설정 절차에는 Google Cloud 프로젝트 선택과 데이터 스토어 Billing 선택이 포함된다. 이는 GCP 사용 금지 조건과 충돌할 수 있다.
- 현재 연결은 테스트에서 동작한 사실과 별개로, 프로젝트 과금 및 조직 정책 적합성이 확인될 때까지 추가 확장·정기 운영을 보류한다.
- Slack 데이터 스토어는 federated 방식으로 검색 요청을 Slack API에 전달한다. 공식 문서만으로 이 POC의 각 조회마다 별도 GCP 비용이 발생하는지는 단정할 수 없다.
- 실제 사용 비용은 Gemini Enterprise 구독 에디션/종량제 여부, 기능 사용량/초과 과금 설정, 데이터 스토어 연결 프로젝트의 Billing, Slack 플랜에 따라 달라질 수 있다. 관리자 확인 전 무료라고 가정하지 않는다.

## 주간 보고 POC 적용

- Slack 데이터 스토어 연동, 주간 데이터 읽기, Slack 메시지 전송은 기능 POC에서 확인했다. 예약 실행 후 메시지 전송 전에 사용자 승인이 필요하다.
- GCP 의존성·과금·정책 적합성이 확인되기 전까지 Slack 데이터 스토어를 허용된 정기 운영 경로로 간주하지 않는다.
- Gmail/GWS 발송, Google Drive 저장, GCP 기반 MCP 서버·스케줄러·Cloud Run은 대안에서 제외한다.
- 이메일 발송은 현재 주간 보고 POC 범위에서 제외하며, 출력은 Slack 메시지로 한다.
- 비용 미확인 연동은 무료로 간주하지 않으며, 확장 및 정기 운영 전에 관리자 확인을 받는다.

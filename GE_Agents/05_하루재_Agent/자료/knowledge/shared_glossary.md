# 하루재 Agent 공통 용어집 (Shared Glossary)

이 문서는 **하루재 Agent** 내 모든 Sub-Agent(`Translation Agent`, `Korean Editing Agent`, `Translation Reviewer`)가 공통으로 참조하는 표준 용어집입니다.
용어집에 등록된 용어는 각 Agent가 임의로 변경할 수 없으며, 문서 전체에서 일관되게 사용해야 합니다.

---

## 1. AI 및 기술 기본 용어

| 원문 (Source) | 표준 번역어 (Target) | 영문 약어 / 병기 규칙 | 비고 |
|---|---|---|---|
| Artificial Intelligence | 인공지능 | AI | 최초 등장 시 '인공지능(AI)' 병기 가능 |
| Machine Learning | 머신러닝 | ML | '기계학습' 대신 '머신러닝'으로 통일 |
| Deep Learning | 딥러닝 | DL | '심층학습' 대신 '딥러닝'으로 통일 |
| Large Language Model | 대규모 언어 모델 | LLM | 최초 등장 시 '대규모 언어 모델(Large Language Model, LLM)' 병기 |
| Agent | 에이전트 | - | 문맥상 소프트웨어 주체를 뜻할 때 '에이전트' 표기 |
| Multi-Agent | 멀티 에이전트 | - | |
| Orchestrator | 오케스트레이터 | - | |
| Prompt | 프롬프트 | - | |
| Inference | 추론 | - | |
| Fine-tuning | 파인튜닝 | - | '미세조정' 대신 '파인튜닝'으로 통일 |
| Grounding | 그라운딩 | - | 필요 시 '근거 연결(Grounding)' 병기 가능 |
| Hallucination | 할루시네이션 | - | 필요 시 '환각 현상(Hallucination)' 병기 가능 |

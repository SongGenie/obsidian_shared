# 신기술 자료 정리

상위 문서: [[GE_Agents/00_GE_Agent_프로젝트_목록]]

## 목표

웹·뉴스·유튜브 등에서 AI 신제품, 신기술, AX 구현 자료를 주간 단위로 정리한다. 자료를 누적 보관하여 나중에 자연어로 다시 검색하고 원문을 열 수 있게 한다. 발송 채널은 미정이다.

## 필수 기능

- 관심 주제·출처·기간을 지정한 자료 수집.
- 중복 기사와 같은 발표의 재배포 자료 통합.
- 원문 링크·발표일·수집일과 함께 핵심 내용 요약.
- 주간 요약본 생성 및 지정 채널로 전달.
- 기술명·제품명·태그·날짜·출처와 의미 기반 누적 검색.
- 검색 결과에 저장된 자료와 원문 링크를 함께 제공.

## 수집 분류

| 분류 | 예시 |
| --- | --- |
| AI 솔루션·신제품 | 모델, API, SDK, SaaS, 개발 도구 |
| 신기술 | 논문, 공식 연구 발표, 오픈소스 |
| AX 구현 | 기업 도입 사례, 자동화 구성, 구현 가이드 |
| 관심 분야 후보 | XR, 웨어러블, OCR, 멀티모달, 온디바이스 AI |

관심 분야 후보는 초기 제안이며 실제 키워드와 우선순위는 별도로 확정한다.

## 추천 구조

1. 매일 또는 매주 공식 블로그·문서·RSS·웹 검색 등으로 후보 수집.
2. 발행일과 실제 발표일을 확인하고 원문 URL 기준 중복 제거.
3. 확보 가능한 본문·설명·자막을 추출.
4. Gemini가 요약·분류·업무 적용 아이디어 생성.
5. 개별 자료와 주간 요약을 저장하고 검색 색인 갱신.
6. 메일 또는 Slack 등 결정된 채널로 요약 발송.

초기에는 Google Drive 문서 기반 보관을 후보로 검토하고 GE 검색 연결을 검증한다. 자료량이 커지면 전용 데이터 스토어를 검토한다. 요약문만 저장하지 말고 권한과 이용 조건 내에서 확보한 원문 정보도 검색 대상으로 보존한다.

유튜브는 제목·설명만 확보한 경우와 자막·본문까지 확인한 경우를 구분한다. 자막을 확보하지 못한 영상을 시청한 것처럼 요약하지 않는다. 뉴스로 발견하더라도 가능한 경우 공식 발표·문서·논문을 근거로 연결한다.

## 개별 자료 저장 형식

```yaml
title: 자료 제목
source_type: official_blog
source_name: 출처명
source_url: 원문 URL
published_at: YYYY-MM-DD
collected_at: YYYY-MM-DD
topics: [AI, AX]
products: []
content_basis: full_text
```

본문 필드: 한 줄 요약, 핵심 내용, 이전 방식과의 차이, 활용 아이디어, 도입 조건·제약, 근거 발췌 또는 확보한 본문, 관련 링크.

발표 사실과 에이전트의 활용 제안을 구분한다. 발표일을 확인하지 못한 자료는 날짜 미확인으로 표시한다.

## 주간 요약 형식

```markdown
# 주간 신기술 브리핑 | YYYY-MM-DD ~ YYYY-MM-DD

## 이번 주 주요 자료
### 자료 제목
- 핵심: 무엇이 발표·변경되었는가
- 활용: 우리 업무에 어떻게 적용할 수 있는가
- 제약: 도입 전에 확인할 조건
- 발표일: YYYY-MM-DD
- [원문](실제_URL) / 저장 자료 링크
```

## 검색 예시

- “지난달에 정리한 안경용 OCR 기술 찾아줘.”
- “AX 사례 중 실제 구현 코드가 있는 것만 보여줘.”
- “전에 봤던 번역 자동화 자료와 원문 링크 찾아줘.”

## 에이전트 지침 초안

> 지정 주제와 기간에 맞는 자료를 수집하고 원문 근거를 우선한다. 중복 발표는 통합하며 발표일과 수집일을 구분한다. 확인된 사실과 활용 아이디어를 구분하고 원문 URL을 보존한다. 제목·설명만 확인한 영상은 확인 범위를 명시한다. 과거 자료 검색 시 저장된 자료를 우선 검색하고 일치하는 자료가 없으면 없다고 답한다.

## 구축 체크리스트

- [ ] 키워드·제외 주제·우선 출처 결정
- [ ] 주간 선정 개수·발송 시각·발송 채널 결정
- [ ] 자료별 저장 위치와 GE 검색 연결 검증
- [ ] URL·내용 기반 중복 제거
- [ ] 정확한 기술명 검색과 의미 검색 평가
- [ ] 출처 접근 불가·날짜 미확인·자막 부재 처리

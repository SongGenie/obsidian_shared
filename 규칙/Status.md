# Status

`status`는 문서 또는 프로젝트의 **현재 진행 단계**를 나타낸다.

```text
기획 → 검증 → POC → 파일럿 → 배포
```

| 값 | 기준 |
| --- | --- |
| `기획` | 목표, 범위, 요구사항을 정리하는 중 |
| `검증` | 권한, API, 데이터, 기술 적용 가능성을 확인하는 중 |
| `POC` | 제한된 범위에서 핵심 기능의 동작을 증명하는 중 |
| `파일럿` | 실제 데이터와 사용자를 대상으로 제한 운영하는 중 |
| `배포` | 정식 사용 및 운영 중 |

## 작성 규칙

- 위의 다섯 값 중 하나만 사용한다.
- 완료한 단계가 아니라 현재 진행 중인 단계를 기록한다.
- 보류 여부는 `status`에 추가하지 않고 별도 속성으로 작성한다.

```yaml
status: 검증
on_hold: true
```

# Tag

`tags`는 문서의 주제, 업무 유형, 서비스, 핵심 기술을 나타낸다.

## 작성 규칙

- 기존 태그가 있으면 같은 표기를 재사용한다.
- 권장 개수는 문서당 `3~7개`이다.
- 같은 의미의 한글·영문 태그를 중복하지 않는다.
- 제품명과 기술명은 공식 표기를 사용한다: `Slack`, `OneNote`, `MicrosoftGraph`, `RAG`, `MCP`.
- 일반 개념은 한글을 우선한다: `검색`, `수집`, `요약`, `자동화`, `예약`.
- 공백, 날짜, 담당자 이름, 진행 상태는 태그로 사용하지 않는다.
- `status` 값을 태그에 중복해서 넣지 않는다.

## 작성 순서

```text
상위 분류 → 업무 분야 → 업무 유형 → 서비스·기술
```

```yaml
tags: [GE, Agent, 주간보고, 자동화, Slack]
```

```yaml
tags: [GE, Agent, OneNote, 검색, RAG]
```

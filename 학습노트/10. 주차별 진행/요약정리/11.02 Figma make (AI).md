## 🧠 Figma Make 기능 개요

|기능|설명|주요 용도|
|---|---|---|
|**Make Design**|텍스트 프롬프트로 UI 레이아웃 자동 생성|“모바일 앱 로그인 화면 만들어줘” → 자동으로 Figma 디자인 생성|
|**Make Code**|선택한 프레임에서 HTML/CSS/React 등 코드 생성|디자이너-개발자 협업 가속|
|**Make Diagram**|Mermaid.js 문법 기반 다이어그램(FigJam)에 자동 생성|플로우차트, 시퀀스 다이어그램, Gantt 차트 등|
|**Make Screenshot / Metadata**|특정 노드의 스크린샷, 구조(XML), 코드 추출|문서화, 코드 반영, QA 자동화|

## 1️⃣ **Make Design**

- 텍스트 기반으로 인터페이스를 자동 생성합니다.
    
- 예시:
    
    `“모바일 청첩장 페이지 만들어줘”`
    
    → Figma가 자동으로 버튼, 이미지, 텍스트 박스 등을 배치한 기본 화면 생성.
    

**핵심 기능**

- 오토 레이아웃, 스타일 가이드 자동 적용
    
- Figma Variables를 활용한 색상/폰트 통합 관리
    
- AI 리비전(수정 제안) 기능: “더 미니멀하게 바꿔줘”
    

---

## 2️⃣ **Make Code**

- 선택한 노드(예: 프레임, 컴포넌트)에서 바로 코드를 생성합니다.
    
- HTML, CSS, React, SwiftUI 등 다양한 언어를 지원합니다.
    

**예시**

- 버튼 컴포넌트를 선택하고  
    `Make → Code → React`  
    → 결과:
    
    `<button className="primary">Sign In</button>`
    
    - 필요한 CSS 코드 자동 생성
        

**활용**

- 디자이너가 만든 시안을 개발자가 바로 코드로 확인
    
- 컴포넌트 시스템 일관성 유지
    

---

## 3️⃣ **Make Diagram (FigJam용)**

- FigJam에서 플로우차트나 시퀀스 다이어그램을 자동 생성합니다.
    
- 내부적으로 **Mermaid.js** 문법을 사용합니다.
    

**예시**

`graph LR A["Start"] --> B["Login Page"] B --> C{"Login Success?"} C -->|Yes| D["Dashboard"] C -->|No| E["Retry Login"]`

→ FigJam 캔버스에 즉시 시각화됨.

**지원 다이어그램 종류**

- Flowchart
    
- State diagram
    
- Sequence diagram
    
- Gantt chart
    
- Decision tree
    

---

## 4️⃣ **Make Screenshot / Metadata**

이건 주로 개발자용입니다.

- `/get_screenshot`: 특정 노드의 캡처 이미지를 추출
    
- `/get_metadata`: 노드의 XML 구조(레이어, 크기, 포지션 등)
    
- `/get_code`: 코드와 관련 asset 다운로드 링크 제공
    

**예시 활용**

- QA 자동화 (디자인 → 코드 비교)
    
- 문서화 자동 생성 (디자인 캡처 포함)

## 💡 Make 기능 활용 팁

|목적|권장 Make 기능|
|---|---|
|아이디어 스케치|**Make Design**|
|개발 코드 추출|**Make Code**|
|데이터 흐름 / 로직 구조|**Make Diagram**|
|테스트 문서나 리포트 자동화|**Make Screenshot + Metadata**|

---

## 🔗 통합 예시 (워크플로우)

1. **FigJam에서** Make Diagram으로 서비스 플로우 작성
    
2. **Figma Design으로 전환** → Make Design으로 UI 초안 생성
    
3. **Make Code**로 React 코드 추출
    
4. QA 단계에서 **Make Screenshot**으로 디자인 캡처 자동화
    

이 과정을 통해 **아이디어 → 디자인 → 코드 → 검증**까지 전 과정을 Figma 안에서 일괄 처리할 수 있습니다.

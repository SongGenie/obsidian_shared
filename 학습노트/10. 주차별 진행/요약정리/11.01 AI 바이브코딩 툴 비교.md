## 🧩 1. **Lovable (lovable.dev)** (실제 사용)

> “AI와 함께 프로덕션급 웹앱을 만드는 no-code + AI-code 플랫폼”

### ✅ 장점

- **AI가 자동으로 코드베이스 생성** → React + Next.js + Tailwind + Supabase 등 실무 스택을 바로 사용 가능
    
- **시각적 편집기 + 코드 편집기** 동시 지원
    
- **실시간 배포 / GitHub 연동** 기능 탑재
    
- 디자인과 백엔드 로직을 한 화면에서 관리 가능 (AI가 백엔드 API 자동 생성)
    
- AI가 “요구사항 기반으로 전체 앱 구조”를 제안해줌 → MVP 개발 속도 매우 빠름
    

### ❌ 단점

- 아직 **베타 단계**라서 안정성이 낮음
    
- **고급 커스터마이징**은 코드로 직접 해야 함
    
- 서버리스 아키텍처 기반이라 대규모 트래픽엔 부적합
    
- 완전한 오프라인 개발 불가
    

### 💡 활용 포인트

> MVP(Minimum Viable Product, 스타트업 아이디어 시제품, 내부용 대시보드, 데모 제작에 적합

## 🤖 2. **AI Studio (예: Google AI Studio / OpenAI Studio)**

> AI 모델을 활용한 **프롬프트 설계 및 API 앱 제작용 스튜디오**

### ✅ 장점

- ChatGPT, Gemini, Claude 등 **대형언어모델(LLM) 기반 앱 제작**에 최적화
    
- 시각적 인터페이스로 **Prompt 설계 / 테스트 / 배포** 가능
    
- **API 키 발급 및 백엔드 연결** 쉬움
    
- JSON schema를 기반으로 빠른 입력/출력 제어 가능
    

### ❌ 단점

- **프론트엔드 UI 구성은 불가능** (코드 직접 작성 필요)
    
- **데이터베이스/스토리지 연동 없음** (별도 Firebase 등 필요)
    
- **엔터프라이즈급 기능 제한** (프로토타입용에 가까움)
    

### 💡 활용 포인트

> AI 챗봇, 문서요약기, LLM 기반 서비스 프로토타이핑에 적합

## 🔥 3. **Firebase Studio (또는 Firebase Console + Extensions + GenKit 등)**

> Google Firebase 기반의 **서버리스 백엔드 및 앱 관리 스튜디오**

### ✅ 장점

- **실시간 DB (Firestore)**, **Auth**, **Storage**, **Hosting** 등 완비
    
- **Firebase Extensions**로 AI/ML 기능도 쉽게 연동
    
- **Google Cloud와 완전 호환** → 스케일링 용이
    
- 모바일·웹·백엔드 모두 지원 (SDK 풍부)
    
- **무료 티어**로 MVP 충분히 개발 가능
    

### ❌ 단점

- UI 기반 “앱 제작 스튜디오”는 아님 → **직접 코드 작성 필요**
    
- **비용이 트래픽/요청 수에 따라 급격히 증가** 가능
    
- 쿼리 제약 조건 (복잡한 join 불가)
    

### 💡 활용 포인트

> 웹/모바일 앱의 백엔드 인프라 구축, 사용자 인증, 실시간 데이터 동기화에 적합

## 🌸 4. **Orchids (Orchids.ai 또는 AI-native IDE 계열)**

> 최근 등장한 **AI-native 개발환경** (예: AI pair programmer + 자동 배포)

### ✅ 장점

- **AI 기반 코드 자동 완성 / 리팩터링 / 문서화**
    
- **Git, Docker, Deploy 파이프라인 통합**
    
- **대화형 명령어**로 프로젝트 전체 구조 관리
    
- 브라우저 IDE + 클라우드 런타임 제공
    

### ❌ 단점

- **아직 실험적 단계** (프로젝트 안정성 낮음, 장기 기억 낮음음)
    
- 특정 언어나 프레임워크에 **최적화되지 않은 경우 많음**
    
- 무료 플랜 제한적 (실행 시간 제한, 프로젝트 개수 제한 등)
    

### 💡 활용 포인트

> 실시간 AI 페어코딩, 자동 배포형 프로젝트, 코드 리뷰 자동화 등

## 💻 5. **Repl.it (현재 이름: Replit)**

> 브라우저 기반의 대표적인 **클라우드 IDE + AI 코딩 플랫폼**

### ✅ 장점

- **100개 이상 언어 실행 환경 지원 (Python, JS, Java 등)**
    
- **Ghostwriter AI**로 실시간 코드 제안 / 자동 완성
    
- **웹앱 호스팅, DB, 패키지 설치, Git 연동** 통합
    
- “Team collaboration” 기능으로 교육, 협업에 강점
    
- **배포 버튼 한 번으로 실행 및 공유 가능**
    

### ❌ 단점

- 대규모 프로젝트엔 비효율적 (빌드 속도 / 파일 수 제한)
    
- **서버 자원 제한** (무료 플랜은 느림)
    
- **보안 취약** 가능성 (코드 전부 클라우드에 노출)
    

### 💡 활용 포인트

> 교육용, 해커톤, 빠른 프로토타입 제작, 간단한 웹 서비스에 최적
